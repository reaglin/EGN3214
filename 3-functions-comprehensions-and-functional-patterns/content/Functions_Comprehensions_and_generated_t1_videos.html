Introduction

A function is a named block of code that you define once and reuse whenever you need it. In Python, you create one with the def statement: you give the function a name, list any parameters in parentheses, and indent the body beneath the colon. When the function finishes, a return statement can hand a value back to the code that called it — and if you omit return, Python quietly returns None. Calling the function by name, with parentheses and any required arguments, is what actually runs that code.

This matters because almost everything that follows in the course is built on functions. Parameter styles, scope rules, recursion, and the functional patterns later in this module all assume you are comfortable with the basic def/return/call cycle. Good habits start here too: descriptive names in lowercase_with_underscores, and a docstring — a triple-quoted string on the first line of the body — that explains what the function does, what it expects, and what it gives back.

As you watch, keep three questions in mind. First, what is the difference between a function that returns a value and one that only prints something — can you use the result in an expression afterward? Second, where does execution go when a return runs, and what happens to any code after it? Third, what does the function need from the caller, and what does the caller get back? Try pausing and predicting the output before the narrator reveals it.
