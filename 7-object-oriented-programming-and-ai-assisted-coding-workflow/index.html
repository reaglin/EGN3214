EGN3214

Module 7 — Object-Oriented Programming and AI-Assisted Coding Workflow

This module introduces the principles of object-oriented programming in Python and explores how AI-assisted coding tools can be integrated into an engineering workflow. Learners will model engineering objects as classes, study inheritance and class hierarchies, and develop critical skills for generating, evaluating, and responsibly using AI-produced code.
