Introduction

NumPy (Numerical Python) is the foundation of almost all scientific and engineering computing in Python. At its core is a single data structure: the ndarray, an N-dimensional array of elements that all share one data type and sit in a contiguous block of memory. That design is what makes NumPy fast — operations are applied to whole arrays at once by compiled code rather than by stepping through items one at a time in Python.

In this course, NumPy is the bridge between the general-purpose Python you already know and real numerical engineering work: sensor data, measurement series, coordinate sets, matrices of coefficients, and simulation results. Before you can create arrays, index them, or do linear algebra, you need a clear mental model of how an ndarray differs from a Python list. A list can hold mixed types and grows easily, but it stores references to scattered objects; an ndarray is fixed in size and homogeneous, which is exactly what allows vectorized arithmetic and the attributes you will rely on throughout the module.

As you watch, focus on four things: what NumPy is and what problems it was built to solve; how an ndarray is created and what it actually stores; concrete comparisons of speed, memory, and behavior between arrays and lists (notice how + behaves differently for each); and the key attributes that describe an array — shape, ndim, size, and dtype. Try typing the examples yourself and printing those attributes for every array you make; it is the fastest way to build intuition for the rest of the module.

How These Videos Support the Learning Outcomes

These videos establish the conceptual groundwork the rest of the module depends on. Understanding that an ndarray is homogeneous, fixed-size, and contiguous explains why creation functions like np.array(), np.arange(), and np.linspace() exist and must be chosen deliberately (MO1), and why element-wise arithmetic and broadcasting work on arrays but not on lists (MO2). The emphasis on shape, ndim, size, and dtype prepares you to reason about which elements you are selecting when you move on to slicing, Boolean masking, and fancy indexing (MO3), and to keep track of dimensions when passing matrices to numpy.linalg for solving systems and finding eigenvalues (MO4). Finally, seeing where NumPy fits among Python's numerical tools motivates its use for descriptive statistics and evaluating mathematical functions over whole datasets at once (MO5).
