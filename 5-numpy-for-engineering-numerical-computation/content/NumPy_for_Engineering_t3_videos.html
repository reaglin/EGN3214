Introduction

Every NumPy workflow begins with getting data into an array. Sometimes that data already exists as a Python list or tuple and simply needs converting; more often, you need to generate it — a time vector for a simulation, a grid of sample points for plotting a function, a matrix of zeros to accumulate results, an identity matrix for a linear algebra step, or random values for a Monte Carlo trial. NumPy provides a dedicated creation function for each of these cases, and choosing the right one makes your code shorter, faster, and easier to read.

In this course, array creation is the foundation everything else rests on. The vectorized arithmetic, indexing, linear algebra, and statistics you will use later all assume you can produce arrays of the right shape and data type to begin with. Pay particular attention to the distinction between np.arange(), which is defined by a step size and excludes the endpoint, and np.linspace(), which is defined by a count of points and includes the endpoint — this difference causes a large share of beginner errors in engineering scripts.

As you watch, keep a few questions in mind: What arguments does each function take, and what does it return? What is the dtype of the resulting array, and when does that matter? How do the shape and reshape operations relate to the number of elements? Try typing each example into your own Python session and then changing one argument at a time to see what happens.
