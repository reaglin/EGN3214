Introduction

In NumPy, arithmetic and mathematical operations are applied element by element across an entire array at once. Writing a + b, a * 2, or np.sin(a) tells NumPy to loop internally in compiled code rather than in Python, which is why vectorized code is both shorter to write and dramatically faster than an equivalent for-loop. The functions that perform these element-wise operations — np.add, np.sqrt, np.exp, np.sin, and many others — are called universal functions, or ufuncs.

This matters for engineering work because measurement data, time steps, node positions, and sensor channels naturally live in arrays. Converting a column of readings from volts to pressure, computing the magnitude of force components, or evaluating a model at a thousand time points all become single expressions. Related ideas follow from the same mechanism: comparison operators (>, <=, ==) applied to an array return a Boolean array of the same shape, which can then be used as a mask, and aggregate reductions such as sum(), mean(), min(), max(), and std() collapse an array down to a summary value, optionally along a chosen axis.

As you watch, pay attention to three things: the shapes of the arrays going into each operation and coming out, when broadcasting lets arrays of different shapes combine (and when it raises an error), and the difference between an operation that returns a full array and a reduction that returns a single number. Try typing the examples yourself and checking .shape and .dtype after each step.
