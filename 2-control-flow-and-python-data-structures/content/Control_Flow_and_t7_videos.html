Introduction

A dictionary is a Python collection that stores data as key-value pairs. Instead of asking for "the item at position 3," you ask for "the value stored under the key 'voltage'." You create dictionaries with curly braces, access values by key, and add, update, or remove entries as your program runs. Because keys are looked up directly rather than by scanning through positions, dictionaries give fast access even when they hold large amounts of data.

This matters in EGN3214 because most engineering data is labeled, not just ordered. Sensor readings tied to sensor IDs, material properties tied to material names, unit conversion factors tied to unit symbols, and student records tied to ID numbers all map naturally onto key-value pairs. Learning dictionaries also sharpens your ability to choose among lists, tuples, dictionaries, and sets, which is one of the central skills of this module.

As you watch, pay attention to four things: the syntax for creating a dictionary and retrieving a value by key, what happens when you assign to a key that does or does not already exist, the methods keys(), values(), and items() and how they drive loops over a dictionary, and the rules about what can serve as a key. Try each example in your own Python environment and deliberately trigger a KeyError so you recognize it later.
