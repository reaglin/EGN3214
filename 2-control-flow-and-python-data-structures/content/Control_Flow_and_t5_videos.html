Introduction

A list is Python's workhorse container: an ordered, mutable sequence that can hold numbers, strings, or even other lists. Because the items keep their order, you can reach any element by its index position, and because lists are mutable, you can change, add, or remove items after the list has been created. In engineering work this maps naturally onto things like a series of sensor readings, a set of measured dimensions, or a queue of simulation results.

In this course, lists are the bridge between the control flow ideas you just met and the data structures that follow. Loops become far more useful once you have a collection to iterate over, and conditional statements become more powerful once you can filter or update the contents of a list. Later in the module you will compare lists against tuples, dictionaries, and sets, so a solid grasp of list behavior gives you the baseline for those comparisons.

As you watch, pay attention to five things: how a list is created and indexed (including negative indices), how items are changed or removed in place, how slice notation selects a sub-range, how a list comprehension compresses a loop into a single expression, and what the common built-in methods such as append, insert, remove, pop, sort, and reverse actually do to the original list. Try typing each example yourself and then changing one value to see what happens.
