Introduction

JSON (JavaScript Object Notation) is a lightweight, text-based format for representing structured data. It looks a lot like a mix of Python dictionaries and lists: curly braces hold key-value pairs, square brackets hold ordered sequences, and values can be strings, numbers, booleans, null, or nested objects and arrays. Because it is both human-readable and easy for programs to parse, JSON has become the default way that web APIs exchange data and that applications store settings and configuration.

In this module you have been working with files and with code that can fail at runtime; JSON sits right at the intersection of those ideas. Python's built-in json module gives you four functions to remember: json.loads and json.load turn JSON text (from a string or a file object) into Python objects, and json.dumps and json.dump turn Python objects back into JSON text (to a string or a file). You will also meet the module's limits — not every Python object is serializable, dictionary keys become strings, tuples become arrays, and malformed input raises a JSONDecodeError that your program should handle gracefully.

As you watch the videos below, pay attention to three things: the mapping between JSON types and Python types, the difference between the functions ending in 's' (string) and those without (file), and formatting options such as indent and sort_keys that make configuration files readable. Try typing the examples yourself and then deliberately break one — delete a comma or a quote — so you can see what error Python reports.
