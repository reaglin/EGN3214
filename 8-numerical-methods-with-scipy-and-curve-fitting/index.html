Module 8 — Numerical Methods with SciPy and Curve Fitting

This module introduces Python's SciPy and NumPy libraries as practical tools for engineering computation. Learners progress from SciPy fundamentals through root finding, numerical integration, polynomial regression, and nonlinear curve fitting, concluding with residuals analysis and end-to-end engineering data workflows.
